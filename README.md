## 🛍️ Mega Market - Elite Superstore Website

Современный, анимированный веб-сайт для супермаркета Mega Market, разработанный с использованием React, Tailwind CSS и Framer Motion.

### ✨ Особенности

- 🎨 **Элегантный дизайн** - современный минималистичный интерфейс
- ⚡ **Плавные анимации** - использование Framer Motion для привлекательных переходов
- 📱 **Адаптивный дизайн** - отлично работает на всех устройствах
- 🎯 **Оптимизирован для продаж** - CTA кнопки и контактная информация
- 🌓 **Высокая производительность** - быстрая загрузка и отзывчивость

### 🚀 Технологический стек

- **React 18** - UI библиотека
- **Tailwind CSS** - утилиты стилей
- **Framer Motion** - анимации
- **GSAP** - продвинутые анимации (опционально)

### 📦 Установка

1. Клонируйте репозиторий:
\`\`\`bash
git clone https://github.com/haker266/mega-market-store.git
cd mega-market-store
\`\`\`

2. Установите зависимости:
\`\`\`bash
npm install
\`\`\`

3. Запустите проект в режиме разработки:
\`\`\`bash
npm start
\`\`\`

4. Откройте [http://localhost:3000](http://localhost:3000) в браузере

### 🏗️ Структура проекта

\`\`\`
src/
├── components/
│   ├── Header.js           # Навигация и заголовок
│   ├── Hero.js             # Главный раздел с Call-to-Action

│   ├── Reviews.js          # Отзывы клиентов

\`\`\`

### 🎯 Разделы сайта

1. **Header** - Навигация и логотип
2. **Hero** - Привлекающий главный баннер с информацией о магазине
3. **Categories** - Интерактивные карточки категорий товаров
4. **Features** - Преимущества и особенности магазина
5. **Reviews** - Отзывы клиентов из Google Maps
6. **Contact Modal** - Быстрый доступ к контактной информации
7. **Footer** - Информация и быстрые ссылки

### 📋 Функциональность

✅ Плавные переходы между секциями
✅ Интерактивные кнопки и ссылки
✅ Модальное окно с контактной информацией
✅ Оптимизированные анимации
✅ Мобильное меню
✅ Интегрированные отзывы

### 🎨 Кастомизация

Легко настроить:
- Цвета в \`tailwind.config.js\`
- Текст и содержание в компонентах
- Контактную информацию в \`ContactModal.js\`
- Анимации через Framer Motion props
